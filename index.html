yt-jellyfin

yt-jellyfin is a personal, non-commercial tool. Its only users are the owner's own Google accounts. It is not offered to anyone else.

It is part of the owner's home media setup. It uses the YouTube Data API to:

  • read the subscription list of the owner's own YouTube accounts;
  • unsubscribe from channels the owner has approved removing;
  • subscribe to channels the owner has approved adding.

Nothing else is read or changed.
